# Hermes Mobile installed

A new **Mobile** tab is available in Hermes Dashboard after the plugin is enabled and the Dashboard/gateway is restarted.

Open **Mobile** to run installability diagnostics and open the PWA on your phone.

Expected user flow:

1. Open Hermes Dashboard and log in if prompted.
2. Open the **Mobile** tab.
3. Click **Open PWA** or copy the shown app URL to your phone.
4. On iPhone Safari: **Share → Add to Home Screen**.
5. On Android Chrome: use the browser install prompt when available.

No manual Hermes core patch is required. The plugin ships prebuilt assets and uses `manifest.json` for compatibility with stock Hermes Dashboard static serving.
